# Tessembly

A compact, extensible format for Tetris piece queues, patterns, and constraints.

Rust draft implementation of `tessembly.rfc2.precedence.v1` is being added on `main`.

**RFC2:** `A>B` means A appears before B; `A<B` means B appears before A.
This is a versioned change from RFC1. Files must not be silently reinterpreted.

No PC solver, replay engine, natural-language processing, or Clearra modification is included.
